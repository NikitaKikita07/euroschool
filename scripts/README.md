# Языковые версии

Исходные страницы находятся в `templates/*.html.in`. Блоки `data-uk` и `data-ru` содержат явные переводы; общие тексты переводятся по `scripts/translations.json`. При добавлении нового общего текста добавьте его перевод в словарь либо используйте явные языковые блоки.

После правок выполните из корня проекта:

```sh
python scripts/build-locales.py
```

Сборка создаёт страницы в `/uk/` и `/ru/`, старые страницы перехода и `sitemap.xml`. Метаданные каждой страницы и языковые ключевые слова задаются в `scripts/build-locales.py`. Язык определяется URL; сохранённые настройки браузера его не переопределяют.

JSON-LD встроен непосредственно в HTML. Общие сведения о школе и их переводы задаются в `scripts/structured_data.py`; вопросы и ответы автоматически извлекаются из видимых FAQ соответствующей страницы. Адрес, телефон, образовательные ступени и время работы сверены с текстом сайта; это не независимая проверка документов школы. Неподтверждённые индекс, координаты и дни работы из старого скрипта не перенесены. Время работы сохранено в ответах FAQ. `js/seo.js` больше не подключается и оставлен пустым для совместимости со старыми ссылками.

Проверка после сборки:

```sh
python scripts/check-locales.py
```

Проверяются языковые ссылки, ресурсы, sitemap, единственный JSON-LD на странице, связи сущностей, язык и соответствие FAQ видимому содержимому.

Публикуйте обе языковые папки и общие ресурсы. `_redirects` задаёт постоянные перенаправления на хостингах с поддержкой этого формата. На другом сервере настройте аналогичные HTTP 301; HTML-переходы работают как запасной вариант и сохраняют параметры и якорь при включённом JavaScript.
